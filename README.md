# 🎴 成人卡牌游戏

一款基于Flask开发的Web卡牌收集游戏，包含抽卡系统、战斗系统、票券系统等完整功能。

## ✨ 功能特色

### 🎯 核心功能

1. **卡牌系统**
   - 5种稀有度：N、R、SR、SSR、UR
   - 普通卡牌：2D画面
   - 金色卡牌（SSR/UR）：3D动态效果
   - 卡牌属性：攻击、防御、生命值
   - 独特技能系统

2. **抽卡系统（Gacha）**
   - 单抽：消耗1张抽卡券
   - 十连抽：消耗10张抽卡券
   - 保底机制：
     - SR保底：每10抽必出SR+
     - SSR保底：每90抽必出SSR+
   - 概率分布：
     - N (普通): 50%
     - R (稀有): 30%
     - SR (超稀有): 15%
     - SSR (特别稀有): 4.5%
     - UR (至臻): 0.5%

3. **票券系统**
   - 初始赠送10张抽卡券
   - 通过战斗获取更多抽卡券
   - 票券消耗记录

4. **战斗系统**
   - 回合制战斗
   - 最多选择3张卡牌出战
   - 随机敌人生成
   - 技能触发机制（20%概率）
   - 战斗胜利奖励：游戏币 + 抽卡券

5. **用户系统**
   - 用户注册/登录
   - 个人仪表盘
   - 资源管理（抽卡券、游戏币）
   - 保底进度追踪

6. **卡牌图鉴**
   - 查看所有可收集卡牌
   - 已拥有/未拥有状态显示
   - 卡牌详细信息

## 🛠️ 技术栈

- **后端**: Python Flask
- **数据库**: SQLite (可切换至PostgreSQL)
- **ORM**: Flask-SQLAlchemy
- **认证**: Flask-Login
- **前端**: HTML5 + CSS3 + JavaScript
- **样式**: 自定义CSS（响应式设计）

## 🚀 快速开始

### 1. 环境要求

- Python 3.8+
- pip

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 运行应用

```bash
python run.py
```

应用将在 `http://localhost:5000` 启动

### 4. 首次使用

1. 访问 `http://localhost:5000`
2. 点击"注册"创建账户
3. 登录后即可开始游戏
4. 初始资源：10张抽卡券 + 1000游戏币

## 📖 游戏玩法

### 抽卡

1. 进入"抽卡"页面
2. 选择单抽或十连抽
3. 查看抽卡结果和保底进度
4. 新卡牌自动添加到收藏

### 战斗

1. 进入"战斗"页面
2. 从拥有的卡牌中选择最多3张
3. 点击"开始战斗"
4. 查看战斗日志和结果
5. 胜利后获得奖励

### 卡牌管理

- **我的卡牌**: 查看已拥有的所有卡牌
- **卡牌图鉴**: 浏览所有可收集的卡牌

## ⚙️ 配置说明

在 `config.py` 中可以自定义：

- **稀有度配置**: 各稀有度的概率和颜色
- **抽卡配置**: 单抽/十连消耗、保底数值
- **初始资源**: 新用户的初始抽卡券和游戏币

```python
# 示例：修改初始资源
INITIAL_TICKETS = 20  # 修改为20张抽卡券
INITIAL_COINS = 2000  # 修改为2000游戏币
```

## 🎨 卡牌稀有度

## 🔧 数据库模型

### User (用户)
- 用户名、邮箱、密码
- 抽卡券、游戏币
- SR/SSR保底计数

### Card (卡牌)
- 名称、稀有度
- 攻击、防御、生命值
- 是否为金色卡牌
- 技能信息

### UserCard (用户卡牌)
- 用户-卡牌关联
- 卡牌等级、经验

### GachaRecord (抽卡记录)
- 抽卡历史
- 抽卡类型（单抽/十连）

### Battle (战斗记录)
- 战斗配置
- 战斗结果和奖励

## 📝 API接口

### 抽卡接口
```
POST /gacha/pull
Body: { "type": "single" | "multi" }
```

### 战斗接口
```
POST /battle/start
Body: { "card_ids": [1, 2, 3] }
```

### 卡牌列表接口
```
GET /cards/api/all
```
