## 一、核心设计理念

### 1.1 三国演义战场特色提炼

**历史战役核心要素：**
- 📖 **兵种相克**：骑兵冲阵、弓兵远攻、步兵防守
- 🎯 **地形影响**：官渡、赤壁、夷陵等经典战役地形决定胜负
- 🧠 **谋略制胜**：空城计、连环计、火攻等智谋的重要性
- 🛡️ **阵型变化**：八卦阵、锋矢阵、鱼鳞阵
- 👥 **武将羁绊**：桃园三结义、五虎上将、江东十二虎臣

### 1.2 设计原则

| 原则 | 说明 | 实现方式 |
|------|------|----------|
| 🎮 **易学难精** | 新手5分钟上手，高手需深入研究 | 基础攻防简单，进阶有兵种、阵型、计谋 |
| ⚖️ **平衡性** | 无绝对强势卡组 | 氪金卡与平民卡有不同战术价值 |
| 🎨 **观赏性** | 战斗过程有视觉冲击 | 骑兵冲锋、火攻蔓延、计谋特效 |
| 🧩 **策略深度** | 每回合有多种选择 | 出牌顺序、目标选择、资源管理 |
| 👨‍👩‍👧‍👦 **全年龄** | 不含暴力血腥，强调智慧 | Q版画风、策略对决、历史文化 |

## 二、兵种克制系统

### 2.1 五大兵种

```
        骑兵
       /    \
    克制    被克
     /        \
   步兵 ←克制← 弓兵
     \        /
    克制    被克
       \    /
        盾兵
         |
       克制
         |
        谋士
```

#### 详细属性表

| 兵种 | 特点 | 克制 | 被克 | 代表武将 | 战术定位 |
|------|------|------|------|----------|----------|
| 🐎 **骑兵** | 高攻低防，首回合+30%伤害 | 弓兵 | 盾兵 | 马超、赵云、吕布 | 爆发刺客 |
| 🏹 **弓兵** | 中攻中防，攻击后排优先 | 盾兵 | 骑兵 | 黄忠、太史慈 | 远程输出 |
| ⚔️ **步兵** | 均衡型，无特殊加成 | 谋士 | 骑兵 | 关羽、张飞 | 主力战士 |
| 🛡️ **盾兵** | 高防低攻，嘲讽技能 | 骑兵 | 弓兵 | 许褚、典韦 | 肉盾坦克 |
| 📜 **谋士** | 低攻防，使用计谋卡 | 弓兵 | 步兵 | 诸葛亮、司马懿 | 辅助控制 |

### 2.2 克制机制

**克制效果：**
- 克制关系：+30%伤害
- 被克关系：-20%伤害
- 互相克制时取消（如骑兵vs盾兵 + 盾兵vs骑兵 = 平衡）

**示例战斗：**
```
马超（骑兵，攻击500） vs 黄忠（弓兵，防御300）
基础伤害 = 500 - 300/2 = 350
克制加成 = 350 × 1.3 = 455
最终伤害 = 455
```

## 三、武将定位系统

### 3.1 六大职业定位

#### 🗡️ 战士（Fighter）
**代表：** 关羽、张飞、典韦、许褚

**特点：**
- 血量：4500-5500
- 攻击：450-550
- 防御：350-450
- 技能：单体高伤害、破防、反击

**典型技能：**
- 关羽【青龙偃月】：对单体造成150%攻击伤害，若目标防御>400，额外+200伤害
- 张飞【咆哮】：眩晕目标1回合，自身下回合攻击+50%

#### 🏹 射手（Marksman）
**代表：** 黄忠、太史慈、吕布

**特点：**
- 血量：4000-4500
- 攻击：550-650
- 防御：250-350
- 技能：多段攻击、穿透、连射

**典型技能：**
- 黄忠【百步穿杨】：连续攻击2次，每次造成70%伤害，无视50%防御
- 太史慈【落雁射】：对后排目标造成200%伤害

#### 🛡️ 坦克（Tank）
**代表：** 曹仁、夏侯惇、周泰

**特点：**
- 血量：6000-7000
- 攻击：300-400
- 防御：500-600
- 技能：嘲讽、护盾、反伤

**典型技能：**
- 许褚【裸衣战】：嘲讽所有敌人，自身获得500点护盾，反弹30%伤害
- 周泰【不屈】：濒死时恢复30%生命值（每场1次）

#### 🧙 法师（Mage）
**代表：** 诸葛亮、庞统、司马懿

**特点：**
- 血量：3500-4000
- 攻击：400-500（计谋伤害）
- 防御：200-300
- 技能：AOE、控制、Buff/Debuff

**典型技能：**
- 诸葛亮【借东风】：对全体敌人造成250固定伤害，若场上有"火攻"状态，伤害翻倍
- 庞统【连环计】：锁链连接2个敌人，一个受伤另一个受到50%相同伤害（持续2回合）

#### 💚 辅助（Support）
**代表：** 华佗、貂蝉、大乔

**特点：**
- 血量：3800-4200
- 攻击：250-350
- 防御：300-400
- 技能：治疗、增益、减益

**典型技能：**
- 华佗【青囊秘术】：恢复友方目标40%生命值，并清除1个负面状态
- 貂蝉【离间计】：使敌方2个单位互相攻击1次

#### ⚡ 刺客（Assassin）
**代表：** 赵云、马超、甘宁

**特点：**
- 血量：4200-4800
- 攻击：500-600
- 防御：280-350
- 技能：暴击、突进、收割

**典型技能：**
- 赵云【七进七出】：攻击敌方血量最低的单位，造成180%伤害，若击杀可再次行动
- 马超【神威天降军】：首回合攻击+80%，造成AOE伤害

### 3.2 稀有度与平衡性

| 稀有度 | 基础属性 | 技能强度 | 获取难度 | 平衡机制 |
|--------|----------|----------|----------|----------|
| N（白） | ⭐⭐ | 无技能 | 极易 | 可作为前排炮灰消耗敌方技能 |
| R（绿） | ⭐⭐⭐ | 简单被动 | 容易 | 某些R卡在特定阵容中不可替代 |
| SR（蓝） | ⭐⭐⭐⭐ | 主动技能 | 中等 | 实用技能，组队核心 |
| SSR（紫） | ⭐⭐⭐⭐⭐ | 强力技能 | 困难 | 需要搭配，单卡不无敌 |
| UR（金） | ⭐⭐⭐⭐⭐⭐ | 终极技能 | 极难 | 强但有明显短板，可针对 |

**反氪金设计：**
- N/R卡可通过"精炼系统"提升至SR品质
- 某些R卡的羁绊组合能力超越单张SSR
- 所有稀有度卡牌都有专属的"传说之路"任务解锁隐藏能力

## 四、战场地形系统

### 4.1 八大经典战场

#### 🏔️ 官渡（平原）
**历史背景：** 曹操以少胜多，火烧乌巢

**地形效果：**
- 骑兵移动速度+1（可攻击后排）
- 弓兵射程+1（可攻击全体）
- 火攻伤害+20%

**推荐阵容：** 骑兵+谋士（火攻流）

---

#### 🌊 赤壁（水域）
**历史背景：** 周瑜火攻，曹军大败

**地形效果：**
- 火攻伤害+50%（连环船效果）
- 水性武将（江东系）防御+30%
- 骑兵攻击-20%（不擅水战）

**推荐阵容：** 火攻流、江东羁绊

---

#### 🌲 夷陵（森林）
**历史背景：** 陆逊火烧连营

**地形效果：**
- 伏兵成功率+30%（首回合可打出埋伏牌）
- 视野-1（无法看到敌方后排手牌）
- 火攻可蔓延至相邻单位

**推荐阵容：** 控制流、火攻流

---

#### ⛰️ 五丈原（山地）
**历史背景：** 诸葛亮北伐，秋风五丈原

**地形效果：**
- 防御方全员防御+20%
- 弓兵占据高地，伤害+30%
- 谋士计谋卡效果+1回合

**推荐阵容：** 防守反击、谋士流

---

#### 🏛️ 虎牢关（关隘）
**历史背景：** 三英战吕布

**地形效果：**
- 仅能上场3个武将（3v3）
- 单体技能伤害+20%
- 羁绊效果翻倍

**推荐阵容：** 高配单卡、羁绊组合

---

#### 🏜️ 祁山（干旱）
**历史背景：** 诸葛亮六出祁山

**地形效果：**
- 火攻伤害+30%
- 水系技能无效（华佗治疗-30%）
- 每回合士气-5（全员攻击-1%）

**推荐阵容：** 速攻流、火攻流

---

#### 🌾 长坂坡（平原+桥梁）
**历史背景：** 赵云七进七出，张飞喝断当阳桥

**地形效果：**
- 桥梁限制：每回合最多1个单位过桥
- 吼声震慑：有机会触发群体恐惧（降低10%攻击）
- 突围奖励：生命低于30%的单位攻击+50%

**推荐阵容：** 刺客流、单挑流

---

#### ❄️ 汉中（雪地）
**历史背景：** 定军山，黄忠斩夏侯渊

**地形效果：**
- 行动速度-1（第1回合无法使用技能）
- 老将（50岁以上）不受影响
- 防御+20%，攻击-10%

**推荐阵容：** 老将组合（黄忠、赵云）

### 4.2 随机事件

每个地形都有概率触发特殊事件：

| 事件 | 触发概率 | 效果 |
|------|----------|------|
| 🌧️ 暴雨 | 10% | 火攻无效，弓兵射程-1 |
| 💨 大风 | 15% | 火攻伤害+50%，随机改变方向 |
| 🌫️ 浓雾 | 10% | 暴击率-50%，计谋成功率+30% |
| ☀️ 烈日 | 15% | 士气每回合-3，水系恢复+20% |
| 🪖 埋伏 | 5% | 随机一方触发伏兵，额外获得1次行动 |

## 五、阵型系统

### 5.1 经典阵型

#### 八卦阵 🔮
```
    谋士
   /  |  \
  坦  战  坦
   \  |  /
    射手
```

**效果：**
- 中央谋士防御+50%
- 计谋卡消耗-1能量
- 诸葛亮使用时效果翻倍

**克制：** 怕集火中央
**适合：** 计谋流、控制流

---

#### 锋矢阵 ⚔️
```
      战
     / \
    骑  骑
   /     \
  射      射
```

**效果：**
- 前排战士首回合必定暴击
- 骑兵冲锋距离+1
- 穿透敌方防线后，后排可直接攻击

**克制：** 怕范围控制
**适合：** 速攻流、骑兵流

---

#### 鱼鳞阵 🐟
```
  战 战 战
  射 谋 射
  坦 坦 坦
```

**效果：**
- 全员防御+15%
- 被攻击时有30%几率反击
- 中路突破困难

**克制：** 怕侧翼包抄
**适合：** 防守反击

---

#### 鹤翼阵 🕊️
```
  骑       骑
   \     /
    战 战
   /     \
  射       射
    \   /
     谋
```

**效果：**
- 侧翼包抄：骑兵可攻击敌方后排
- 弓兵交叉火力+20%
- 谋士安全性提升

**克制：** 怕中路强突
**适合：** 分割包围战术

---

#### 长蛇阵 🐍
```
战-战-战-战-射
```

**效果：**
- 单路纵深，前排倒下后排自动顶上
- 每损失1人，后排全员攻击+10%
- 适合消耗战

**克制：** 怕范围AOE
**适合：** 车轮战、持久战

---

### 5.2 阵型转换

- 战斗中可消耗1次行动机会转换阵型
- 部分武将有"阵法师"被动，可免费转换
- 阵型转换有1回合延迟生效

### 7.2 怒气系统

**怒气获取：**
- 受到伤害：+10怒气
- 击杀敌人：+30怒气
- 友军阵亡：+50怒气
- 满值：100怒气

**怒气技（必杀技）：**
- 关羽【单刀赴会】：对全体敌人造成200%伤害，自身进入"武圣"状态2回合（免疫控制，攻击+80%）
- 诸葛亮【七星灯】：复活1个阵亡的友军（50%血量），或对敌方造成全屏500固定伤害
- 赵云【百鸟朝凤枪】：7连击，每次随机目标，伤害递增（100%/120%/.../180%）
- 貂蝉【闭月】：魅惑全体敌人2回合，使其攻击力降低50%并有30%几率攻击队友

---

### 7.3 士气系统

**士气影响：**
- 高士气（80-100）：暴击率+15%，攻击+10%
- 正常士气（50-79）：无影响
- 低士气（20-49）：攻击-10%，防御-10%
- 溃败（0-19）：有几率逃跑（该回合无法行动）

**士气变化：**
- 己方阵亡：-15士气
- 击杀敌人：+10士气
- 使用鼓舞技能：+20士气
- 连续受挫（3回合未造成击杀）：-5士气/回合

游戏中随机出现天气变化（每5回合检测一次）：

| 天气 | 效果 |

| 🌦️ 雨天 | 火攻伤害-50%，水系技能+30% |
| 🌪️ 大风 | 弓兵射程+1，火攻可能失控 |
| ❄️ 雪天 | 移动速度-1，防御+20% |
| ☀️ 晴天 | 士气恢复速度+50% |
| 🌫️ 雾天 | 命中率-20%，计谋成功率+20% |

## 八、平衡性设计

### 8.1 防沉迷机制

**时间限制：**
- 未成年：每日1小时
- 成年：建议每局20分钟，设置健康提醒

**防上瘾设计：**
- 无自动战斗（需要玩家思考）
- 每日挑战次数限制（鼓励合理安排时间）
- 长时间游戏收益递减

---

### 8.2 付费平衡

**公平竞技原则：**

| 玩家类型 | 获胜率目标 | 实现方式 |
|----------|------------|----------|
| 免费玩家 | 40-45% | 送基础强力卡组，签到获得SR |
| 小R玩家 | 45-55% | 月卡性价比高，获得品质资源 |
| 中R玩家 | 50-60% | 卡池深度提升，阵容多样性 |
| 大R玩家 | 55-65% | 满配角色，但需要技术操作 |

**氪金与技术比例：**
- 🎮 技术占60%：出牌顺序、目标选择、阵型克制
- 💰 氪金占40%：卡牌稀有度、培养度

**反氪金机制：**
- 排位赛采用"禁卡"规则（每场可禁用3张对方卡牌）
- 竞技场采用"选秀模式"（双方从相同卡池随机选择）
- 每月有"平民专场"（仅限N/R/SR卡参赛）

---

### 8.3 胜率平衡

**动态调整：**
```python
# 伪代码示例
if card.win_rate > 55%:
    card.nerf(attack=-5%, cost=+1)
    announcement("本周调整：XXX卡牌过强，进行微调")

if card.usage_rate < 2% and card.rarity >= SR:
    card.buff(skill_cooldown=-1)
    announcement("XXX卡牌使用率过低，进行增强")
```

**每月调整周期：**
- 前两周：数据收集
- 第三周：公布调整方案，玩家讨论
- 第四周：正式调整
