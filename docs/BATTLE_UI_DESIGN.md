## 三、交互流程

### 3.1 完整战斗流程

```
战斗开始
  ↓
[1] 显示地形、天气、羁绊激活动画
  ↓
[2] 我的回合开始
  ↓
  ├→ 选择行动：
  │   ├→ 普通攻击：点击我方卡牌 → 点击敌方目标
  │   ├→ 使用技能：点击"技能"按钮 → 选择目标
  │   ├→ 使用计谋：拖拽计谋卡到目标
  │   ├→ 切换阵型：点击阵型按钮 → 选择新阵型
  │   └→ 释放必杀：点击满怒气卡牌 → 选择目标
  ↓
[3] 动画播放：攻击/技能特效
  ↓
[4] 伤害结算：飞出数字、更新血条
  ↓
[5] 状态更新：士气变化、buff/debuff更新
  ↓
[6] 检查胜负：全灭判定
  ↓
  ├→ 继续战斗 → 回到步骤2
  └→ 战斗结束 → 结算界面
```

### 3.2 操作方式对比

| 操作 | PC端 | 移动端 |
|------|------|--------|
| 选择卡牌 | 点击 | 点击 |
| 查看详情 | Hover | 长按 |
| 使用技能 | 点击技能按钮 | 点击技能按钮 |
| 使用计谋 | 拖拽卡牌 | 点击卡牌→点击目标 |
| 切换阵型 | 点击下拉框 | 点击打开面板 |
| 释放必杀 | 点击满怒气卡牌 | 点击满怒气卡牌 |

### 4.2 动画特效

#### 攻击动画

| 兵种 | 动画效果 |
|------|----------|
| 🐎骑兵 | 冲刺轨迹 → 撞击敌人 → 返回 |
| 🏹弓兵 | 拉弓动作 → 箭矢飞行 → 命中 |
| ⚔️步兵 | 向前挥刀 → 刀光特效 → 收刀 |
| 🛡️盾兵 | 盾击前推 → 震荡波纹 → 归位 |
| 📜谋士 | 挥动羽扇 → 法阵浮现 → 消散 |

#### 技能特效

```
火攻类：
  火球生成 → 轨迹飞行 → 爆炸火焰 → 燃烧状态

控制类：
  魔法阵浮现 → 锁链/光环包裹 → 眩晕星星环绕

增益类：
  光芒从脚下升起 → 覆盖全身 → buff图标飞出

治疗类：
  绿色光点汇聚 → 治疗波动 → 血条上涨
```

#### 必杀技分镜动画

```
关羽【单刀赴会】：
  1. 屏幕变暗，聚焦关羽
  2. 关羽马上挥刀，青龙偃月刀泛光
  3. "单刀赴会"4个金色大字飞入
  4. 刀光横扫屏幕
  5. 所有敌人被刀气命中
  6. 巨大伤害数字爆炸
  7. 屏幕恢复正常
```

## 五、响应式设计

### 5.1 断点设计

```css
/* 超大屏（2K/4K显示器） */
@media (min-width: 1920px) {
  .battle-card { width: 180px; }
  .font-size: 18px;
}

/* 标准桌面（1080p） */
@media (min-width: 1280px) and (max-width: 1919px) {
  .battle-card { width: 150px; }
  .font-size: 16px;
}

/* 笔记本/平板横屏 */
@media (min-width: 768px) and (max-width: 1279px) {
  .battle-card { width: 120px; }
  .font-size: 14px;
  .hide-non-essential-info;
}

/* 手机横屏 */
@media (min-width: 480px) and (max-width: 767px) {
  .battle-card { width: 90px; }
  .simplified-layout;
}

/* 手机竖屏 */
@media (max-width: 479px) {
  .vertical-layout;
  .battle-card { width: 70px; }
  .minimal-info;
}
```

### 5.2 移动端优化

**简化信息显示：**
- 隐藏实时战斗日志（改为弹窗查看）
- 合并士气+能量到一个条
- 羁绊信息仅显示图标（点击查看详情）
- 地形效果折叠（点击展开）

**触控优化：**
- 按钮最小尺寸44x44px（iOS规范）
- 卡牌间距增大避免误触
- 拖拽改为点选模式
- 增加操作确认弹窗

## 附录：技术栈建议

### 前端框架选择

**方案A：原生JavaScript（当前）**
- ✅ 优点：轻量、可控、性能好
- ❌ 缺点：代码量大、维护难

**方案B：Vue 3 + TypeScript**
- ✅ 优点：组件化、响应式、易维护
- ❌ 缺点：学习成本、打包体积

**方案C：React + Redux**
- ✅ 优点：生态丰富、状态管理强
- ❌ 缺点：复杂度高、过度设计

**推荐：** 当前项目保持原生JavaScript，复杂系统考虑Vue 3迁移

### 动画库

- **GSAP**：专业动画库，适合复杂动画
- **Anime.js**：轻量级，适合简单动画
- **CSS Animations**：性能最优，适合基础效果

**推荐：** GSAP（复杂技能） + CSS（基础动画）

### UI组件库

- **Element Plus**：完整组件库（如需Vue）
- **Tailwind CSS**：实用优先的CSS框架
- **自定义CSS**：当前方案，完全可控

**推荐：** 保持自定义CSS，配合CSS变量

## 总结

新系统前端UI优化核心思路：

1. **信息分层**：重要信息大而明显，次要信息折叠隐藏
2. **视觉引导**：用颜色、动画、箭头引导玩家操作
3. **即时反馈**：每个操作都有明确的视觉/听觉反馈
4. **渐进披露**：新手看到简化版，高手可展开详情
5. **响应式**：一套代码适配所有设备
